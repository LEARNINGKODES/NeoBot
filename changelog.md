# Changelog

## v1.0.0
- Lanzamiento inicial de NeoBot.
- Sistema de grabación de macros con inputs táctiles (Android).
- Sistema de reproducción frame-perfect.
- Guardado y carga de macros en formato JSON.
- Auto-guardado al completar o salir del nivel.
- Safe Mode para bloquear envío de scores al leaderboard.
- Indicador visual (REC/PLAY) en pantalla durante la grabación/reproducción.
- Menú accesible desde el PauseLayer.
- Compatible con Geometry Dash 2.2081 en Android con Geode.
